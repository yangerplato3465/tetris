# Anti-Pillars

| We will NOT | Because it would compromise |
|---|---|
| Ship persistent meta-progression between runs | Difficulty tuning and run independence — unlocks make every run a function of account age, not play |
| Ship multiplayer or a versus mode | [[P4-numbers-decompose]] and the entire scope; the enemy is a damage schedule, not an opponent |
| Ship board-size, gravity, or rule variants per floor | [[P3-the-board-is-honest]] — the board's rules are the constant against which builds are measured |
| Ship a spell that wins a fight without a line clear | [[P1-two-payout-curves-one-engine]] and [[P3-the-board-is-honest]] — the caster is a *build*, not a bypass |
| Ship enemy status effects or damage-over-time | [[P4-numbers-decompose]] (damage stops decomposing) and scope (an unbounded status machine) |
| Add a new playable class before existing classes are ship-quality | Content-count creep — the failure mode where Weaver and Monk stay half-tuned while class 3 gets built |

## Deliberately left open

Candidates, not commitments:

- [[Q3-currency-cap]] — a cap on currency/resource types.
- [[Q2-enemy-board-interference]] — a ban on enemy board interference beyond garbage rows (column locks,
  hold disable, input inversion).

## Note on the no-rule-variants line

[[R2-central-bet-unfalsified]] is dangerous precisely because its fallback fix — a board-level differentiator
between archetypes — collides with the third row of this table. A pillar renegotiation is part of that risk's cost.
